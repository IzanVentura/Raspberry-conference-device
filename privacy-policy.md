# Privacy Policy

This application is developed and maintained by an individual developer for personal and non-commercial use. It is designed to automate participation in video conferences via a Raspberry Pi device and does not collect, store, or share any personal information from users.

The application uses Google OAuth 2.0 solely to access the user's Google Calendar in order to detect upcoming meetings. No calendar data is stored or transmitted outside the local device, and no analytics, cookies, or tracking mechanisms are implemented.

Access to Google APIs is performed securely and only for the purpose of identifying relevant calendar events. All credentials are kept private and local to the machine where the application is running.

By using this application, you acknowledge that:

- No personal data is stored remotely.
- Your Google account credentials are handled securely via OAuth.
- The developer is not responsible for any misuse or unauthorized use of the software.

If you have any questions or concerns regarding this policy, please contact the developer via the GitHub repository.
